# Финансовый анализатор транзакций

Курсовой проект для анализа личных финансов на основе банковских выписок в формате Excel. Проект считывает данные, рассчитывает метрики для главной страницы, предоставляет сервисы кешбэка/инвесткопилки и формирует автоматические отчеты

## Структура проекта

* `data/` — папка с исходным файлом выписки (`operations.xls`)
* `logs/` — папка со служебным логом (`project.log`) и автоматически сгенерированными JSON-отчетами (генерируется сама)
* `src/` — исходный код проекта:
  * `main.py` — главная точка входа, запускает все расчеты и выводит дашборд
  * `views.py` — логика Главной страницы (приветствие, расчеты по картам, топ транзакций, курсы валют и акций)
  * `services.py` — сервисы аналитики (повышенный кешбэк по категориям и расчет инвесткопилки)
  * `reports.py` — генерация отчетов по категориям за 3 месяца и декоратор сохранения в файл
  * `utils.py` — утилиты для безопасного чтения Excel-файлов и очистки данных
* `tests/` — юнит-тесты и интеграционные тесты для всех модулей системы, покрытие 95%
* `user_settings.json` — пользовательские настройки (выбор дефолтной категории для отчетов и лимита копилки)
* `.env` — файл с приватным API-ключом для курсов валют

## Как запустить проект

1. Убедитесь, что ваш файл выписки лежит по пути: `data/operations.xls`
2. Настройте зависимости и активируйте окружение с помощью Poetry:
   ```bash
   poetry install
   ```
3. Запустите главный скрипт:
   ```bash
   poetry run python src/main.py
   ```

После запуска в консоли отобразится удобный финансовый дашборд, служебные логи запишутся в `logs/project.log`, а автоматический файловый отчет за 3 месяца сохранится в `logs/report_spending_by_category_*.json`

## Запуск тестов и проверка покрытия

Для запуска тестов выполните команду:
```bash
poetry run pytest -v
```

Для проверки покрытия кода тестами прямо в консоли:
```bash
poetry run pytest --cov=src --cov-report=term-missing -v
```
